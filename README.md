# Sistema de Gestão de Clientes

Sistema de cadastro e gerenciamento de clientes desenvolvido em Java, com menu interativo via terminal.

## Funcionalidades

- Cadastrar clientes (nome, email, telefone)
- Listar todos os clientes cadastrados
- Buscar clientes por nome

## Tecnologias

- Java 25
- Programação Orientada a Objetos (POO)

## Como executar

1. Clone o repositório
2. Acesse a pasta `src`
3. Compile: `javac Cliente.java SistemaClientes.java Main.java`
4. Execute: `java Main`
